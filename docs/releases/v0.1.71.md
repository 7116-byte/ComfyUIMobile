# v0.1.71 预览

全部原生页面统一为随系统深浅色切换的创作界面。手机采用底部导航，平板采用侧边导航与分栏内容。

- “任务”整合为“后台”：工作站地址、连接状态、重连和服务器详情与任务记录集中展示，其他页面去掉重复的 IP、队列和版本说明。
- 参数页整理为当前工作流、部件卡片及生成操作；平板增加流程目录，另存与表单布局收进菜单。结果页统一作品筛选和平铺/相册切换，设置支持平板分类栏。
- 搜索、摘要及筛选随内容滚动，顶部标题可收起；切换页签保留目录、筛选与滚动位置。键盘弹出时让出内容空间，并暂时隐藏手机导航与生成操作。
- 修复部分桌面启动器重复创建主页面造成连接页重新出现的问题；Activity 重建时恢复原连接，回到前台时重试已中断的连接。
- 隐藏的前端桥接容器禁用无障碍访问并阻止键盘焦点进入。保留原有复杂控件、工作副本、临时导入和草稿规则。
- 任务取消及清空服务器等待队列需确认；已完成任务卡片减少无内容的留白，小屏按钮避免不必要的换行。

此版本仍在独立包名的手机、平板预览中，尚未发布。完整布局、验证与恢复边界见 [界面说明](../design/adaptive-interface.md)。

构建验证：171 项 JVM 测试中 170 通过、1 项原有可选网络测试跳过；7 组桥接回归、正式构建、lintVitalRelease 与原签名校验通过。
