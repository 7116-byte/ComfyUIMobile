# v0.1.73

新增新手引导，整理项目首页，并修复更新检查长时间没有反馈的问题。

## 第一次使用更清楚

- 首次打开提供连接工作站、打开工作流、保存作品和排错四步引导，可跳过；连接页“使用指南”和设置“新手引导”均可重新打开。
- 引导状态保存在本地；已有连接记录的用户升级不强制重走，不改变工作流、草稿和作品保存开关。
- 讲明启动器、便携版 `.bat`、手动 Python 启动，如何找电脑 IP，以及 LAN、VPN、云实例的兼容边界。
- 补齐可展开的 Windows 防火墙步骤：网络类型、`wf.msc`、入站 TCP 端口、专用配置文件、可信 IP 作用域及复测。
- 新安装不再预填维护者工作站地址；对于不支持的路径代理、用户名密码或查询令牌链接，明确提示而不是静默丢掉部分地址。

## 更新检查

- GitHub API、镜像和官方发布页同时检查，任一来源返回有效结果即结束，取消其他请求。
- 更新检查最多等待 12 秒，失败或超时明确提示，不再把失败当成最新版本。
- 更新页显示“正在检查更新”和进度条，检查期间防止重复点击；结果保留在页面中。

## 项目首页

- 首页改为产品介绍、手机 / 平板截图、下载、三步上手与兼容表；开发和迁移资料集中到文档索引。
- 增加英文介绍、连接与使用手册、贡献指南、问题与建议模板。

沿用原包名和签名，可直接覆盖旧正式版。APK 附有 SHA-256 校验文件。原数据格式、连接历史和本地作品保存规则不变。
