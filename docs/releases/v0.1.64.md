# v0.1.64

- 修复 `QwenImage21MultiImageUpload` 一类 `image_list_upload` 自定义字段在 App 中只显示为普通文本、无法从相册选择多张图片的问题。
- 使用 Android 系统照片选择器一次选择最多 16 张图片，按选择顺序逐张上传并追加到已有列表；与 ComfyUI-ReferenceChain 网页控件的顺序及去重语义一致。
- 参数页显示编号列表，并支持前移、后移、单张移除、清空；提交给 ComfyUI 的值保持为 JSON 字符串数组，例如 `["主图.png","参考图.png"]`。
- 上传任一图片失败时不覆盖此前成功项；图片原文件直接上传，不压缩、不转码。空列表保持合法，仍可执行纯文本生成。

验证：使用服务器真实的 `QwenImage21MultiImageUpload` `/object_info` 定义与工作流字段核对；Android 单元测试、桥接回归、Release 构建和签名检查。
