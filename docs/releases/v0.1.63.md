# v0.1.63

- 加快初始化：网页已加载过节点定义后，App 不再额外下载一遍完整 `/object_info`；移除未使用的 `/features` 请求和就绪探测的额外启动延时。
- 加快重连：手动重连、网络切换、WebSocket 自动重连先检查现有网页，健康时直接恢复连接，不再重载网页和工作流；页面失效时仍可完整恢复。
- 保留重连前的画布、未保存参数、工作流预读状态和任务跟踪；重复点击不会反复打断同一次连接。
- 图片查看使用独立的全屏窗口，修正顶部露出主界面、底部操作按钮裁切的问题，系统栏临时显示时控制条不随之跳动。
- 增加初始化等待阶段与连接耗时日志。

验证：桥接就绪与复用脚本回归、已有参数和标签回归、Android 单元测试、Release 构建和签名检查。当前没有连接 Android 实机，手机端初始化实际耗时与全屏显示仍需实机确认。
