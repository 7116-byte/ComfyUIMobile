# v0.1.68

- 修复后台任务监控服务的启动/停止时序：创建服务即建立前台通知，每次启动在重复任务和过期进度判断前重新确认前台状态；任务刷新复用已运行的监控，合并短时间内的重复启动请求。
- 空闲停止在主线程延迟合并，并使用最新启动序号调用 `stopSelfResult`；系统还有未处理的新启动请求时不撤掉前台通知。完成任务不因滞后的列表刷新再次启动监控，保存阶段不被迟到的生成进度覆盖。
- 历史退出追踪移到后台扫描，结果列表解析移到后台，减少主线程繁忙对服务启动的影响。
- 图片全屏浏览的“更多”增加“查看参数”：本地原图优先读取内嵌生成记录，云端优先读取与该图片输出匹配的任务历史，历史缺失时回退原图。支持 PNG 文本元数据及 ComfyUI WebP/AVIF EXIF 元数据（AVIF 原图元数据依赖 Android 12+）；可复制参数、关闭返回当前图片。
- 参数按对应输出的上游节点分组，显示提示词、模型/LoRA、种子、采样器、步数、尺寸等记录字段。优先展示实际执行 Prompt 的种子，保留完整整数；若只有工作流控件快照则明确标明可能为生成前设置。查看参数不加载前端画布、不修改当前工作流、不写入服务器工作流文件。

验证包含 Android 服务生命周期模拟（重复启动、保存中进度、启动与空闲停止交错）、参数输出链过滤、大整数种子、PNG 压缩元数据/CRC 校验和原有回归。WebP 使用真实字节样本；AVIF 使用真实 EXIF 字节及原生媒体索引测试替身，未替代手机解码器验证。正式包与旧版保持同一签名。没有连接 Android 实机，手机端最终表现仍需安装后确认。
