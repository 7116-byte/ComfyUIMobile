# v0.1.59

- 原图下载：支持大文件 2–4 路 HTTP Range 并发，覆盖手动保存、后台自动下载及分享。
- 校验分段范围、总长、文件版本、实际字节数和合并完整性；不支持分段时自动回退普通下载。
