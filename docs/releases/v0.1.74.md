# v0.1.74

扩展完整 ComfyUI 实例的 HTTPS 连接，并在设置中加入项目入口。

- 支持 HTTPS 根地址。缺省端口使用 443，自定义端口保留；现有 HTTP 连接与默认 8188 行为兼容。
- HTTPS 任务进度通道使用 WSS，服务器名称从真实主机解析，结果与原图继续使用 HTTPS 地址。
- 原生 API 不自动跟随重定向，避免连接到平台登录页或降级协议；原图下载保留原有重定向策略。
- 隐藏桥接和高级编辑严格匹配协议、主机及端口；证书错误会取消连接，不添加信任所有证书或忽略主机名的开关。
- 登录页、HTTP 401 / 403、接口重定向给出针对性说明。
- 设置中的“GitHub 项目”直接打开 `7116-byte/ComfyUIMobile` 仓库；连接页、首次引导及文档同步更新。
- 引导与教程按通用云端实例说明外部 HTTPS 地址与内部映射端口的区别，加入自定义端口格式回归，不按平台品牌分别配置。

当前范围是可直达的完整 ComfyUI 实例。平台账号 / Cookie / API Key、令牌链接、路径前缀代理、应用分享页及纯 API / Serverless 仍需要独立适配，不宣称任意云平台已经验收。

本地验证：204 项 JVM 测试中 203 通过、1 项原有可选网络测试跳过；7 组桥接回归、正式构建、lintVitalRelease 和原签名校验通过。新增 6 项 TLS 集成检查使用本地真实加密套接字和运行时生成的短期测试证书，覆盖 HTTPS、WSS、系统信任拒绝、登录页、403 和重定向。信任该测试证书的配置仅在 JVM 测试中使用，App 继续使用系统证书信任。云平台示例、默认 / 自定义端口、同源边界和 HTTPS 历史持久化亦有回归覆盖。

真机验证：平板预览版原位升级为 0.1.74-debug，成功连接自定义外部端口的真实 HTTPS 云实例，读取到 ComfyUI 0.37.0、前端 1.53.6 和 2,020 个节点定义；独立 WSS 探测成功，原始前端初始化、服务器信息和空工作流目录显示正常。重启后 HTTPS 连接记录与原有 HTTP 工作站均保留。该实例没有已保存工作流，未对真实工作流参数或生成进行验收。
