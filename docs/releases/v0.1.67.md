# v0.1.67

- 从生成结果图片或本地 PNG、WebP、AVIF、JSON 文件打开工作流时，只建立手机当前会话中的临时工作副本，不自动写入 ComfyUI 服务器。可直接查看、修改参数、进入高级编辑和提交生成；只有明确点击“保存”或“另存”才创建服务器工作流文件。
- 参数页标明“临时工作流，尚未保存”。临时副本不会进入服务器工作流列表或“最近打开”，也不会被误判为服务器文件丢失/冲突；重连时继续使用当前内存副本。未保存的临时副本在 App 进程结束后不保证恢复。
- 保存临时副本时创建独立工作流 ID；如目标名称后来被其他工作流占用，要求另存，避免误覆盖。服务器写入成功但前端标签刷新失败时仍明确报告保存成功，并在下次操作重载标签。
- 前端就绪诊断改用 ComfyUI 的安全 `isGraphReady` 状态，不再因探针过早读取 `rootGraph` 而制造 `graph accessed before initialization` 控制台错误；日志增加工作流列表是否正在同步的状态。

验证：Android 单元测试、桥接脚本回归、Release 构建、关键 Lint、签名与包元数据检查均通过；签名证书与 v0.1.66 相同。APK SHA-256：`6c29e09a70c0c2db1ebbca70b922924bd423e240c260df24635a808b8595ced5`。手机实机行为仍需安装后验证。此前自动保存到服务器的杂乱工作流不会自动删除。
