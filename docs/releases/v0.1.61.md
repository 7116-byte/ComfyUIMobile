# v0.1.61

- 修复 Wi-Fi、移动网络或 VPN 变化后连接停在错误状态：监听默认网络变化并完整重建 ComfyUI 接口、网页桥接和 WebSocket；连接同一服务器时保留当前任务跟踪状态。
- 右上角按钮显示为“重连”，点击后直接重新连接当前服务器，不再只做一次数据刷新。
- 图片查看在全屏窗口出现前先隐藏系统栏，减少状态栏先缩动再消失的过渡；退出查看后恢复系统栏。
- 图片“更多”菜单增加“打开工作流”：读取图片原始字节中的 ComfyUI 工作流，使用不冲突的新名称保存到工作流根目录并打开参数页，不覆盖已有工作流。
- 首页长按工作流只选中，不触发预读或加载；复制、改名、导出、删除和移动均可对选中项操作，移动时从服务器现有目录列表选择目标位置。
- 没有修改 VPN、代理或反向隧道配置。
