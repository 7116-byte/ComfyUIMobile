# v0.1.65

- 修复 v0.1.64 的参数分类回归：节点类型 `QwenImage21MultiImageUpload` 中带有 Image/Upload，导致该节点下的正向提示词、负向提示词和分辨率都被错误显示成单图上传控件。
- 媒体控件现在只根据具体字段名称、控件类型和 `image_list_upload` 标记判断，不再让节点名称污染其他字段。
- `prompt`、`negative_prompt` 按服务器 `multiline=true` 定义显示多行文本；`resolution` 按 `INT` 显示整数输入；只有 `images` 显示有序多图上传。
- 空负向提示词保持合法，不再产生“尚未选择文件”的假错误，生成按钮恢复可用。

验证：对当前 ComfyUI 0.37.0 服务器的 `QwenImage21MultiImageUpload` 五个必填字段逐项核对，并增加正向提示词、负向提示词、分辨率和图片列表的分类回归测试。
