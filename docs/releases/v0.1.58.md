# v0.1.58 — 参数、工作副本与任务跟踪修复

- 参数改回初始值也会正确提交，包括模型切换、LoRA 小数强度；未变化的网页控件不重复触发回调。
- 复制、改名、移动、导出明确读取目标工作流，避免预读与参数页切换后串图；再次打开不会用旧预读数据覆盖当前编辑。
- 接管优先使用执行时快照；后续生成和高级编辑沿用该快照，不因同名文件变化而换图。
- 按服务器持久化接管记录，恢复后台登记任务；失败和队列移除可正常结束监控。
- 完成/保存消息明确关联服务器和任务；其他任务的保存完成不会覆盖当前进度。
- 明确接管的任务可按本地输出白名单保存；未配置该任务的输出类型不会被误判为保存失败。
- 历史刷新可修正漏掉的完成事件并清除旧绿框；旧连接回调、重复预读不会覆盖新状态。
- 取消运行任务使用按任务 POST 接口，不在失败后发送可能误伤其他任务的全局中断。旧服务器不支持时会提示。

## 跨客户端进度边界

ComfyUI 原生接口只向提交任务的客户端发送实时节点事件。本 App 自己提交的任务可实时跟踪；电脑浏览器提交的任务可以接管执行快照、跟踪队列/完成和本地保存，但实时绿框仍需要服务器端只读进度接口。本次不抢占浏览器会话，不自动安装服务器插件。
