# v0.1.69

- 移除“参数名包含 seed 就添加随机数按钮”的逻辑。种子快捷操作由实际控件提供：rgthree 的“每次生成随机”调用原生按钮并保持 `-1`，“生成新的固定种子”单独保留。不支持随机操作的普通数字不再出现多余按钮。
- 通过子图输入连线定位真实控件，支持改名后的子图暴露种子。普通采样器仅在实际关联 `control_after_generate` 时提供随机/固定模式，遵循控件本身的范围；不再由 Android 生成可能超出网页安全整数范围的大数字。
- 补齐子图内的生成前、提交成功后控件回调，以及子图暴露控件的生成后控制，避免随机模式不推进、参数页把旧种子反复写回。提交失败不执行生成后处理。
- 工作副本从实时画布单独读取，保留随机节点的特殊模式；提交到服务器的工作流和图片元数据记录本次使用的具体种子。种子按钮操作不再重新载入整个工作流，保留节点的上次种子状态；“使用上次排队种子”兼容按钮已显示为具体数字的情况。
- 打开手机参数时，不再对未变化的控件重复调用参数回调。排队后刷新失败不会把已成功提交的任务报告为提交失败；先记录并监控已接受任务，再刷新参数。
- 新增原生种子动作、子图别名、重复生成及元数据分离回归；HTTP 提交测试验证完整保留子图、连线、扩展字段和大整数，并且不调用工作流文件保存接口。原有临时导入、就绪、工作流标签等回归保留。

## 本次排查的边界

- 已有原图内包含 `prompt` 和完整 `workflow`，没有发现 APP 删除工作流元数据。当前检查到的 ComfyUI 前端在使用任务资产接口时收到 HTTP 404，电脑提交和 APP 提交的任务均有同样结果。这属于服务器/网页前端兼容问题，不能靠重装手机 APP 修复；本版没有擅自修改服务器内核、网页包、插件或网络配置。
- 电脑“未手动编辑却提示保存”未完成现场复现。自动种子推进、插件回填、版本迁移都可能触发网页的修改比较；本版不强制清除修改状态、不自动保存或覆盖服务器工作流。
- 验证：160 项 Android/JVM 测试，159 项通过、1 项原有可选网络测试跳过、0 失败；7 组桥接脚本回归通过；正式构建与发布检查通过。未连接 Android 实机，以上不等同于手机端最终验证。
