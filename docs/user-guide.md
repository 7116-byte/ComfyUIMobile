# 从工作流到作品

首次启动可阅读四步引导，也可跳过；连接页“使用指南”和“设置 → 新手引导”随时可重新打开。引导不会自动连接、生成或修改服务器。已有连接记录的用户升级后不强制重走引导。

## 连接工作站

需要你自己的 ComfyUI；完整配置见 [连接教程](connection-guide.md)。局域网、已互通 VPN 和云平台完整实例有不同前提。当前只支持 HTTP 根地址，不支持平台登录或纯 API 链接。

连接页可手动输入、扫描当前网段的默认 8188 服务，或选择已保存的工作站。地址在网络请求前记录；记录不等于已经验证连接成功。重新打开 App 时，可用已保存地址再次连接；电脑换 IP 后需要更新地址。

## 选择与编辑

1. 在“工作流”搜索或进入文件夹。单击只选择并预读取参数。
2. 点悬浮的“打开参数”进入表单。展开部件，调整提示词、种子、模型、单图或有序多图。
3. 特殊画板、遮罩或曲线等控件，用悬浮的“高级编辑”进入服务器原始前端，关闭后同步回工作副本。
4. 确认无失效模型或节点错误后，主动点“生成”。后台页可查看队列和任务。

错误及完成提示显示在顶部标题附近，可点击查看完整内容；切换主页面仍可查看。浮动操作不会随表单滚动丢失，列表可上下浏览；手机和平板采用不同布局。

## 工作流什么时候保存？

修改参数先改变手机工作副本。只有明确点击参数页的“保存 / 另存”才写回服务器；回桌面、关闭高级编辑或生成都不等于保存服务器文件。

“设置 → 工作流草稿”默认关闭。开启后，对已经保存的服务器工作流保留本地草稿；服务器版本变化时可选择继续草稿、读取服务器版或另存。图片 / 文件临时导入工作流只留在当前会话，需要手动保存才能长期保留。导出文件也可用来单独备份。

## 把结果留在手机

“结果 → 云端”展示工作站输出；“本地”展示已下载到 App 的作品。看到缩略图不代表原图已经保存在手机。

自动保存需要同时满足：

1. 在参数页长按有效输出部件，加入本地保存白名单。
2. 在“设置 → 本地作品”开启自动保存，确认相应规则已启用。
3. 任务由本 App 提交，或由你明确接管，并命中该工作流的输出规则。

也可在结果中手动保存原图。App 不自动收集所有浏览器任务。云端删除不会影响已经保存的本地作品。重要作品请另存或导出到相册 / 文件，清除 App 数据或卸载前尤其要备份。

图片可全屏缩放、拖动和左右切换；“更多 → 查看参数”只读查看记录，不会覆盖当前工作流。视频支持流式查看与保存，音频等暂不提供专用播放器。

## 后台、更新与反馈

后台页合并工作站信息、队列、任务与进度。本 App 提交的未完成任务可通过前台通知跟踪；是否授权通知由用户决定。其他客户端任务可接管队列 / 完成状态，但 ComfyUI 不向本 App 额外推送另一客户端的实时节点进度。

未连接时也能进入“设置 → 软件更新”。v0.1.73 起显示检查中状态和持久结果，所有来源失败时明确报错；安装更新会校验 SHA-256、包名、版本和正式证书。旧版检查异常可从 [Release](https://github.com/7116-byte/ComfyUIMobile/releases/latest) 下载覆盖安装，避免卸载丢失数据。

需要求助时，在“设置 → 诊断日志”导出日志并遮盖私人内容，附上版本、连接类型、复现步骤和脱敏截图 [反馈问题](https://github.com/7116-byte/ComfyUIMobile/issues/new/choose)。
