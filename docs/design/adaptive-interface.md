# 自适应界面 v0.1.71

本次统一连接、工作流、参数、结果、后台和设置页面，已完成手机和平板对照并发布 v0.1.71。正式版沿用原包名和签名；用于真机对照的预览版使用独立包名 `com.local.comfyuimobile.debug` 和“ComfyUI Mobile 预览版”名称，两者可以并存。

## 布局

- 跟随系统深浅色，统一蓝色主操作、柔和背景、文字层级、卡片圆角与间距。
- 连接页在可用宽度达到 720dp 时采用两栏；手机保持单栏，主连接按钮占满表单宽度，服务器列表避免横向挤压。
- 主界面在窗口宽度达到 720dp 时使用侧边导航，较窄时使用底部导航。
- 工作流列表在自身可用宽度达到 660dp 时，将当前选择及“打开参数”放在右侧；较窄时放在列表上方。
- 复制、改名、移动、导出和删除收进工作流操作菜单，删除仍经过原确认流程。点击预读、长按选择、双击打开的业务逻辑保持一致。
- 参数页保留工作流切换、保存、编辑部件和生成；另存与表单布局收进操作菜单。平板提供可滚动的流程目录，点击部件可展开并定位。输入控件、输出白名单、错误检查和高级编辑的业务行为保持原有规则。
- 原任务页更名为“后台”，集中显示工作站地址、连接状态、重连、可展开的版本/显卡/显存信息及任务记录。其他页面移除重复的服务器副标题；连接异常时保留前往后台的入口。
- 结果统一为本地/云端作品切换、平铺/相册视图；窄屏也能显示两列缩略图。长按多选保留，系统返回可以退出选择；任务取消和清空等待队列增加确认。
- 设置在平板采用左侧分类、右侧内容；分类和详情都可滚动。手机保持逐级进入详情的结构。

## 滚动、键盘与返回

- 工作流搜索与选择、参数摘要、结果筛选、后台连接信息均进入页面滚动内容，向上浏览时主标题栏也会收起。
- 各页使用独立保存状态，切换页签后保留目录、筛选、展开与滚动位置。
- 键盘弹出时内容区域让出键盘高度；手机底部导航与参数页生成操作暂时隐藏，关闭键盘后恢复。
- 隐藏的桥接容器和 WebView 禁用无障碍访问，容器阻止后代获取键盘焦点；高级编辑使用自己的可见 WebView，不受影响。尚未进行完整 TalkBack 验收。
- 桌面入口采用 singleTop，并关闭少数启动器创建的重复 MAIN Activity，避免新 ViewModel 将已有会话显示成连接页。Activity 重建时重接原服务器，后台连接失败时回到前台会尝试恢复。
- 页面状态恢复不改变草稿开关：进程被系统终止后，未开启本地草稿的修改和临时导入内容仍不能保证恢复。

## 验证

Robolectric 原生渲染检查覆盖 320dp 放大字体、393dp 手机、430dp 深色手机、776dp 平板竖屏和 1163dp 平板横屏。截图位于 `app/build/outputs/adaptive-preview`，使用测试数据，不是实际用户作品。

原生测试覆盖全部页面、任务确认弹窗和服务器详情；长列表额外检查四页均可滚动到末尾、上方控件离开视口、切换页签后保留位置。构建验收与真机观察分开记录，后者保存在未跟踪的 `.local/live-device`。

最终一键验收共 171 项 JVM 测试，170 项通过、1 项原有可选网络测试跳过；7 组桥接脚本回归、正式构建、lintVitalRelease、原签名及包名/版本检查通过。代表性测试截图见 [截图索引](../screenshots/README.md)。

真机对照中，手机为 1440×3200、600dpi、字体倍率 1.0；平板为 2136×3200、440dpi、字体倍率 1.25。两台均安装预览版，成功显示连接页、真实工作流列表、参数及后台信息。已实测 44 项目录的纵向滑动、顶部控件收起、参数下部内容和平板目录定位。早期手机远程触摸不稳定时由用户确认手动进入正常；后续通过键盘和可用的 ADB 触摸继续检查，未因此改变工作流手势。

两台分别通过 3 轮“桌面停留 20 秒 → 普通桌面入口打开”，进程和主页面实例保持一致，任务栈中仅一个主页面，后台页与在线状态保留。键盘测试确认手机和大字体平板的输入框位于键盘上方；浅色系统栏文字对比度已修正。两台完成深浅主题切换对照后恢复原浅色设置。未执行系统杀进程或生成任务验收。

平板直接访问局域网工作站。手机访问局域网地址超时，本轮通过临时 ADB USB 反向转发访问同一工作站；没有改动 VPN、路由或服务器配置。没有启动生成任务，没有保存、删除或修改服务器工作流。调试切屏已停止，USB 常亮及深浅主题已恢复原值；手机临时转发保留供现场预览使用，结束后移除或拔掉 USB。记录位于 `.local/live-device/device-session.json`。

## Comfy API 的关系

用户截图中的“部署到 Comfy API”是官方托管部署入口：将工作流的模型、自定义节点和环境打包成云端服务，需要付费套餐，并另计 GPU、存储费用。相邻的“导出（API）”用于导出程序执行的工作流 JSON。

当前 App 已使用自托管 ComfyUI 的 HTTP / WebSocket 接口，并通过前端桥接处理复杂工作流及自定义控件。本次视觉预览没有接入云端服务。将来如需离开自有电脑运行，可评估新增可选的 Comfy API v2 后端；动态编辑、控件回调与 API 执行数据仍需要分别处理，不能直接删除前端桥接。

来源：[官方 Comfy API 说明](https://support.comfy.org/articles/2703236295-comfy-api-deploy-your-comfyui-workflow-as-an-api)、[官方自托管 API 代理](https://github.com/Comfy-Org/comfy-api-proxy)。
