# 参数页提示与悬浮操作槽 · v0.1.72 开发预览

参数页将校验错误、生成进度、完成状态和操作提示放在顶部“参数”标题旁，位于工作流摘要卡上方，不再放入工作流卡片或底部。主标题栏使用透明背景和文字、图标阴影，上滑时常驻；内容区域在标题栏下方独立滚动，避免正文与标题重叠。

较窄屏幕的长提示最多显示两行，多条状态各显示一行；点按可查看和复制完整内容。校验错误继续显示在对应部件中；临时操作提示可关闭，并沿用原有提示时长，其他页面仍使用原有 Snackbar。

“高级编辑”和“生成”组合为带轻阴影的圆角悬浮槽，手机底部居中，平板位于参数区域右下角。按钮保留文字、启用条件及生成前的本地输出确认；滚动内容末尾留出 96dp，最后一个部件可完整滚到操作槽上方。键盘弹出时操作槽隐藏，输入区域继续避让键盘。

原生检查包含 320dp 大字体、常见手机宽度和平板横竖屏；检查错误/完成状态均位于工作流卡片上方、长列表上滑后仍然可见、长提示全文弹窗、提示关闭、末尾不被遮挡及生成前确认。完成提示使用测试状态验证，不触发真实生成。

真机检查与本地渲染分开记录，现场截图保存在忽略目录 `.local/live-device`。手机锁屏时使用对应尺寸的原生渲染，不将安装成功视为手机显示验收。

此前平板实测报警位于“参数”标题旁、工作流卡片上方；连续上滑后提示位置不变，摘要卡离开视口。长提示全文与完成状态使用原生测试检查，没有提交真实生成任务。

后续修正将“打开参数”从可滚动的选择卡片移到悬浮圆角槽，并显示目标工作流名称。顶部反馈覆盖所有已连接的主页面，切换到工作流、结果和后台后仍显示当前工作流错误及生成状态。

连接选择在有效地址归一化后、网络请求前提交到 DataStore；成功探测后继续更新最后在线时间和版本。存储名称与原有字段不变，预览版与正式版依旧各自保存数据，不自动相互迁移。新增真实文件关闭再打开的测试，验证已成功连接和只尝试连接的地址、重复去重及其他设置写入后的保留。该测试没有复现用户设备杀进程丢记录的原始原因，也不能替代正式版真机验收。

最新一键验收共 178 项 JVM 测试，177 通过、1 项原有可选网络测试跳过；7 组桥接回归、正式构建、lintVitalRelease 与原签名校验通过。本轮没有连接的 Android 设备，最新修正尚未安装到真机。

此版本仅更新独立预览包，GitHub 正式发布仍为 v0.1.71。
