# 参数页提示与悬浮操作槽 · v0.1.72 开发预览

参数页将校验错误、生成进度、完成状态和操作提示集中放入顶部的白色工作流摘要卡，不再使用底部错误说明或独立的生成状态卡。校验错误继续显示在对应部件中；参数页的临时操作提示可关闭，并沿用原有提示时长，其他页面仍使用原有 Snackbar。

“高级编辑”和“生成”组合为带轻阴影的圆角悬浮槽，手机底部居中，平板位于参数区域右下角。按钮保留文字、启用条件及生成前的本地输出确认；滚动内容末尾留出 96dp，最后一个部件可完整滚到操作槽上方。键盘弹出时操作槽隐藏，输入区域继续避让键盘。

原生检查包含 320dp 大字体、常见手机宽度和平板横竖屏；新增顶部错误/完成状态、提示关闭、末尾不被遮挡及生成前确认检查。完成提示使用测试状态验证，不触发真实生成。

一键验收：174 项 JVM 测试中 173 通过、1 项原有可选网络测试跳过；7 组桥接回归、正式构建、lintVitalRelease 和原签名校验通过。两台设备均已更新独立预览版；平板实测顶部校验提示及悬浮槽，键盘弹出后操作槽隐藏且输入框可见。手机当时处于锁屏，显示检查使用对应小屏原生渲染，未将安装成功视为手机真机验收。

此版本仅更新独立预览包，GitHub 正式发布仍为 v0.1.71。
